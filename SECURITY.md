# Security policy

Nullset Decision Compiler is an inspectable decision-support prototype.

- Keep credentials, private evidence, and operational datasets out of Git history.
- Validate external inputs and bound report, export, and query sizes.
- Preserve provenance for evidence and clearly label seeded or simulated content.
- Review generated decisions before acting on them; the prototype is not a substitute for domain expertise.
- Avoid adding network, shell, or file-system access without a threat-model review.

Report injection, data disclosure, unsafe file handling, or authentication issues privately to the repository owner.
